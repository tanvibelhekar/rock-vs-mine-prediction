Rock vs Mine Prediction

This is my first Machine Learning project, where I built a model to predict whether an object is a rock or a mine using sonar data.

I followed a YouTube tutorial and used Google Colab to understand how a basic machine learning project works.

Technologies Used

- Python
- NumPy
- Pandas
- Scikit-learn
- Google Colab

Dataset

The project uses sonar data containing signal readings to classify rocks and mines.

Project File

- "Rock_vs_Mine_Prediction.ipynb" – Jupyter Notebook containing the code.
- "sonar data.csv" – Dataset used for prediction.

What I Learned

- Basic concepts of Machine Learning
- Working with datasets
- Training and testing a model
- Making predictions using Python

This project helped me get started with Machine Learning and gain some hands-on practice.
